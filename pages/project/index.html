09 · TIME SERIES

ARIMA Forecast

A simple ARIMA workflow: inspect a series, fit a baseline model, and compare its short-range forecast with observed values.

PythonPandasStatsmodelsARIMA
View simple example +
from statsmodels.tsa.arima.model import ARIMA

# Monthly observations in chronological order
series = [102, 108, 105, 115, 112, 120, 118, 127, 123, 132, 130, 138]

model = ARIMA(series, order=(1, 1, 1))
fit = model.fit()
forecast = fit.forecast(steps=3)
print(forecast)
